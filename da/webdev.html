Full-Stack-webengineering

Over 7 års erfaring i at levere produktionsklare webprodukter ende-til-ende i TypeScript - Nuxt 3 og Next.js i frontenden, Node / Express i backenden og AWS- + Docker-leveringspipelinen, der binder det hele sammen. Denne side følger selve webengineering-arbejdet: typede grænser fra database til UI, komponentmønstre, der holder, efterhånden som funktionerne hober sig op, og freelance- og open source-projekterne undervejs.

Aktuelt fokus

  • -Type-sikre API-grænser fra database til UI i TypeScript
  • -Nuxt 3 / Vue 3- og Next.js / React-komponentmønstre i stor skala
  • -Node / Express-tjenester med realtidslevering via WebSocket
  • -AWS-, Docker-, Kubernetes- og Jenkins-CI/CD-pipelines
  • -Produktionsovervågning med Sentry, Google Analytics og Amplitude

Udvalgt arbejde

FreeConvert

[Produktion · Nuxt 3 + Node]

En af de højest rangerede SaaS-platforme til online filkonvertering, -komprimering og -transkodning. Frontend i Nuxt 3, backend-tjenester i Node / Express, realtidsfremdrift over WebSocket, deployet på AWS + Kubernetes + Cloudflare. Millioner af konverteringer om måneden.

Visitnorth_east

ProPDF

[Produktion · Nuxt + PDF-editor]

En PDF-editor i browseren leveret som et nyt SaaS-produkt i TransMedia-porteføljen. Opsatte Jenkins- + Docker-CI/CD-pipelinen fra bunden og byggede den funktionsrige redigeringsflade ende-til-ende.

Visitnorth_east

EnviroConfig

[Open Source · Node-pakke]

Env-konfiguration og skemavalidering til Node. Fanger fejlkonfigurerede deployments ved opstart, så produktion aldrig bliver overrasket af en manglende nøgle. Multi-miljø-defaults indbygget.

GitHubnorth_east

node-express-rate-limiter

[Open Source · NPM-pakke]

En Express.js-rate-limiting-middleware med tilpasselige regler, IP-whitelisting, Redis-baserede tællere og burst-håndtering. Bygget til ægte produktionstrafik, ikke kun demoer.

GitHubnorth_east

vue3-counter

[Open Source · Vue-komponent]

En meget tilpasselig numerisk tæller-komponent til Vue 3 med fleksible layouts, styling-muligheder og fuld TypeScript-understøttelse. Lille overflade, ægte ergonomi.

GitHubnorth_east

ProPassword

[Open Source · Next.js-app]

En privacy-first, klientside-adgangskodegenerator med frasebaseret generering, entropianalyse og flersprogsunderstøttelse. Bygget med Next.js, TypeScript, Redux Toolkit og Tailwind.
